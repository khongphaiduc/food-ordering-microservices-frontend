##  About This Project
This is a **ReactJS frontend** for a food ordering website.

No overengineering.  
Just clean UI, smooth flow, and coding by vibe.

Users can browse food, add to cart, and place orders with a simple and intuitive experience.

---

##  What It Does
- Browse food menu 
- View product details 
- Add to cart 
- Place orders 
- Basic authentication UI 
- AI-powered personalized recommendations
- Admin Interface
---

##  Tech Stack
- ReactJS
- JavaScript
- HTML/CSS
- Axios
- React Router
